jst a simple mod that adds **immersive titles** that appear when entering a new **biome/structure**. The thing is simple: a big title with the biome/structure name **filling the screen on the first visit** to the biome/structure, along with a small name appearing in the bottom-left corner, **also showing the biome/structure's name on subsequent visits.**

And if u're still **thinking about whether u should download this mod or not**, then please allow me to help u make a decision. In the [Gallery](https://modrinth.com/project/immersive-titles/gallery) section, u can see an image that shows what the in-game title actually looks like, along with the small title. And yes, it's animated. I mean, yeah, it's not the best animation in the world, but it does its job, ig :p
